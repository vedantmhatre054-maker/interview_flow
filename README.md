# InterviewFlow

## Project Overview

InterviewFlow is a Flutter app that helps students track their interview preparation.

Users can select a subject, mark topics as completed, and see their progress. The app shows both subject-wise progress and overall preparation progress.

---

## Features

* Track interview preparation
* Mark topics as completed
* View subject progress
* View overall progress
* See completed and remaining topics
* Simple and user-friendly interface

## Future Enhancement (Idea 1)

In future versions, users will be able to add their own subjects and topics instead of using only the predefined subjects.

For example, users can create custom subjects such as Flutter, Aptitude, Python, or any other topic they want to study. They will also be able to add and manage their own topics inside those subjects.

This feature will make the application more flexible and useful for different users.

## Conclusion
